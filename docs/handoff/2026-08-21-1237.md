## Implemented

- Job association observes `ctx.jobs.onJobsChanged` in the same ALS capture, tracks per-capture Job-set deltas, snapshots roots at Job publication, and requires the structured `jobId` result to agree.

- Managed shutdown calls only owner-fenced `jobs.kill` + bounded `jobs.wait`, or exact-owner `terminals.kill` + public-session quiescence check. Failure returns a structured failure and never escalates to PID/process-tree termination.
- `runtimeInspector.shutdown()` is exposed; unload/dispose clears observer state without calling DSH owner teardown or process primitives.
- Result correlation is bounded and cleared on attribution disposal; listener output carries optional Job/Terminal owner ids.
