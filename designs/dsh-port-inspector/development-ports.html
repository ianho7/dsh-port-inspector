开发端口的识别范围

系统使用项目、会话、进程链与工具链等明确线索组织列表。常见端口号只用于补充说明，不会单独决定归类。

Vite · Server options开发服务器端口可自动顺延，因此端口号不是稳定身份。
Docker · Port publishing容器服务会映射到主机端口，需要识别映射关系而非只看宿主进程。
Microsoft · WSL networkingWSL 服务可以通过 Windows localhost 访问，系统代理进程不等于无关进程。
Firebase · Local Emulator Suite一次开发任务可能同时启动多个本地服务和端口。
React Native · Metro移动开发工具链同样包含长期监听的本地服务。
Ollama · Local API本地 AI 服务属于现代开发环境的一部分。
