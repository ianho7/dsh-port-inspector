# 06: 固定显示与偏好持久化

**What to build:** 允许用户把默认隐藏的监听器固定到开发端口视图，并在 Browser reload 后保留该偏好。固定显示只改变 Browser 展示，不改变 Host 分类、来源或操作权限。

**Blocked by:** 02: 开发环境与其他监听分流.

**Status:** resolved

- [x] “其他监听”行提供可访问的固定/取消固定操作，固定项进入独立“固定显示”分组。
- [x] 偏好使用有命名空间和版本的 Browser 本地状态，并在 reload 后恢复。
- [x] 稳定展示身份不包含 PID 或创建时间；项目运行时按工具链与项目区分，桌面应用按稳定 executable 身份区分。
- [x] 固定项不在开发端口计数中重复计算，搜索和全部监听也不产生重复行。
- [x] 无效或过期偏好安全忽略，存储不可用时交互在当前页面内仍可使用。
- [x] 固定、reload、取消固定和权限正交性通过 Browser 行为测试。

实现说明：固定偏好保存在 Browser 的 `dsh-runtime-inspector:pins:v1` 本地状态中；稳定键使用应用身份，或项目 basename、路径哈希与工具链组合，不含 PID/创建时间。存储异常只影响跨 reload 持久化，不影响当前页面交互。类型检查及持久化、分组、计数聚焦测试通过。

## Answer

固定显示已实现为 Browser-only 偏好。固定项进入独立“固定显示”分组，不增加“开发端口”计数；刷新恢复、取消固定、无效版本和存储失败路径均有测试覆盖。
